# DSA-Practice

A collection of data structures & algorithms practice problems, examples, and notes. This repository contains small, focused C++ examples and snippets used while learning and revising common DSA topics.

## Repository structure

- `C++STL/` — Short example programs demonstrating STL containers and usage (vector, map, set, stack, queue, etc.).
- `Topics/` — Algorithm and data-structure practice files (arrays, bitwise ops, pointers, strings, math, etc.).

Example files:

- `C++STL/vector_STL.cpp` — `vector` examples
- `Topics/Array_operations.cpp` — array practice

## Getting started

Prerequisites: a C++ compiler (g++, clang++, or MSVC). To compile and run an example:

```bash
# compile (example)
g++ -std=c++17 Topics/Array_operations.cpp -O2 -o array_ops
# run
./array_ops
```

On Windows with MinGW use the same commands in Git Bash or run via your IDE.
